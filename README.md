# XOLERIC — My Cube (cub)

Interactive 3D cube experience with cross-window synchronization. Multiple browser windows can "merge" their cubes through proximity, transforming from a cube into a quantum torus knot.

## Features
- 3D cube with dynamic canvas texture
- Cross-window BroadcastChannel sync
- Cube → Torus Knot morphing on merge
- Neural network particle system
- Matrix rain background
- Bloom post-processing
- Real-time FPS counter

## How to open
Open `index.html` in multiple browser windows and move them close together.
